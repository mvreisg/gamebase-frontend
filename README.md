# Gamebase-Frontend

A simple frontend application for the Gamebase API.

Using [Vite](https://vite.dev/) and [TypeScript](https://www.typescriptlang.org/).

Has [ESLint](https://typescript-eslint.io/) and [Prettier](https://prettier.io/) support.

## Running with Docker

### Setup

Not implemented yet.

## Commands

See `package.json` on the project root folder.

```
npm run dev
```

Starts the server!

```
npm run lint
```

Runs the linter.

```
npm run format
```

Runs the formatter.
